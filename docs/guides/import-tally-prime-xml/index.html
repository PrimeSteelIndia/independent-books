Migration Guide

How to Import Tally Prime XML into Independent Books

Migrating accounting software is usually delayed because business owners fear losing historical transactions or spending weeks reconciling ledger discrepancies. Independent Books provides a native Tally Prime XML importer designed to migrate your Chart of Accounts, opening balances, inventory items and Day Book vouchers without proprietary converters.

This step-by-step guide walks through the exact export screens in Tally Prime, the XML file structure, how the import engine handles partial batches, and how to verify opening balances against your Tally trial balance before posting live entries.

Prerequisites before exporting from Tally Prime

Before generating the XML export, complete all pending voucher entries for the target period and take a complete backup of your Tally company data folder.

Next, generate and export a detailed Trial Balance from Tally Prime (Gateway of Tally → Display More Reports → Trial Balance, press Alt+F5 for Detailed view). Save this as a PDF or spreadsheet — it serves as your source of truth for post-import balance verification.

  • Verify company books are closed for the export period
  • Export detailed Tally Trial Balance to PDF or Excel for comparison
  • Ensure your user account in Tally has administrator export privileges
  • Take an offline backup of your Tally company data directory

Step 1: Export Masters from Tally Prime

In Tally Prime, navigate to the Gateway of Tally and press Alt+E (Export), then select Masters.

Press C (Configure) to review the export settings: set Format to 'XML (Data Interchange)', set Type of Masters to 'All Masters', and set Include Dependent Masters to 'Yes'.

Specify your export folder and set the filename to Master.xml. Press Ctrl+A to accept configuration, then press E (Send) to generate the XML file. This file contains your account groups, ledgers, party GSTINs, units of measure and stock items with opening balances.

Step 2: Export Transactions (Vouchers) from Tally Prime

Return to Gateway of Tally, press Alt+E (Export), and select Transactions.

Press C (Configure): set Format to 'XML (Data Interchange)' and Type of Vouchers to 'All Vouchers'. Set the Period date range (e.g., 01-Apr-2025 to 31-Mar-2026). Exporting one completed financial year at a time is recommended for precise reconciliation.

Set Include Dependent Masters to 'Yes' and specify the export filename as DayBook.xml. Press E (Send) to export the transaction records.

Step 3: Import XML into Independent Books

Open Independent Books on your desktop. If starting fresh, create a new company database and confirm that your home State and GSTIN match your Tally company profile so tax rules align.

From the Gateway menu, press Alt+G (Go To) or select Import → Import Tally XML. Browse and select your Master.xml file.

Independent Books validates the XML structure and presents an import preview listing the count of Ledgers, Groups, and Stock Items detected. Click 'Execute Import'. The import runs inside an atomic SQLite transaction.

Once masters are imported, repeat the process with DayBook.xml to ingest your sales, purchases, payments, receipts, contra and journal vouchers.

Handling partial imports and error logs

If an imported voucher references a ledger name that was omitted from Master.xml or contains an unrecognized statutory field, Independent Books logs the specific XML line number and error detail to an import log.

Because imports execute in atomic batches, database integrity is never corrupted by partial syntax errors. You can review the log, create any missing ledger in Masters, and re-run the voucher import without duplicating existing records.

Step 4: Reconcile opening balances and trial balance

Once the import completes, press Alt+G → Trial Balance in Independent Books. Set the report date to match your Tally export cutoff date.

Verify that Total Debits equal Total Credits and that the 'Difference in Opening Balances' ledger displays zero.

Cross-check your Sundry Debtors, Sundry Creditors, Cash-in-Hand, and Bank Account totals against the Tally Trial Balance PDF you exported in the prerequisite step. When the totals match to the paisa, your migration is complete.

Questions

Can I import multiple financial years from Tally?

Yes. Import Master.xml first to establish all ledgers, then import voucher XML files in chronological order financial year by financial year.

Are party GSTINs and HSN codes preserved?

Yes. The XML parser extracts party GSTIN, state code, HSN/SAC codes, and default tax rates directly from Tally's ledger and stock item XML elements.

Does this process touch or alter my original Tally data?

No. The process reads only the exported XML file. Your original Tally installation and company data directory remain completely untouched.

What should I do if the Trial Balance shows an opening balance difference?

Compare the opening balance of each parent Group (Capital, Fixed Assets, Current Assets) against Tally to pinpoint which ledger was missed or adjusted in Tally after the export.
