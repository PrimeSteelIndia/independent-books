Tally Prime vs Independent Books

This comparison is written from the position that Tally Prime is a mature commercial product and Independent Books is a young open source one. The useful question is not which is better in the abstract, but which costs you less for the specific work you do.

Licensing and cost

Tally Prime is licensed per serial, with renewal and upgrade costs that recur for as long as you need current statutory support. Independent Books is MIT licensed with no recurring fee. Over five years the difference for a single-PC business is on the order of a hundred thousand rupees or more, which is the headline number.

Data ownership and format

Tally stores company data in proprietary files that require Tally or a specialised tool to read. Independent Books stores a standard SQLite database, readable by any SQLite client, plus a JSON backup export. For an auditor or a future migration, that difference is decisive.

  • Tally: proprietary binary, export via XML/ODBC
  • Independent Books: SQLite file, plus JSON backup
  • Both: double-entry with two-sided statements

GST and compliance depth

Tally has years of statutory edge cases implemented — e-invoicing, e-way bill, detailed GST return preparation, audit forms. Independent Books handles the core billing split (CGST/SGST intra-state, IGST inter-state) and leaves portal filing to you. If you rely on Tally for return preparation, that is a genuine reason to keep paying.

Workflow and staff retraining

The core keys match: F2 for date, F4–F9 for voucher types, Alt+G to navigate, Ctrl+A to accept, and the same two-sided statement layout. Staff who know Tally can post on day one. Deep configuration screens do not map one-to-one, so an administrator will notice the difference even if a data-entry operator does not.

Where Tally is clearly the right answer

Multi-branch consolidation, statutory audit tooling, payroll, a large consultant ecosystem, and a support line you can escalate to. A business that depends on any of these should not switch to save money — the support relationship has value.

Questions

Can Independent Books open Tally .900 files?

No. Use Tally's XML export and the built-in XML importer.

Is the keyboard workflow identical?

The voucher and navigation keys match; configuration screens differ.

Does it do e-invoicing?

No. It generates the invoice and the ledger entry.

Is it supported commercially?

No, support is community-based.
