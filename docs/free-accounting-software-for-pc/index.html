Free Accounting Software Download for PC

Two builds are published for Windows, and the choice between them matters more than it looks. The installer registers shortcuts and is the right choice for a machine that stays in one place. The portable ZIP is a folder you can run from a USB stick or a synced drive, and leaves nothing behind on the host machine.

Neither build asks for an email address, and neither phones home on first run.

Which download to pick

Pick the installer if this is the accounts PC and the same person uses it every day. Pick the portable build if you move between machines, if IT policy forbids installs, or if you want to keep the application and the books together on removable media.

  • Windows installer — 8.3 MB, .exe, desktop and Start menu shortcuts
  • Portable ZIP — 18.7 MB, no install, runs from any folder or USB drive
  • macOS — 14.3 MB DMG for Apple Silicon and Intel
  • Linux and Android — server mode, opened in any browser

The SmartScreen warning, explained

The binaries are not signed with a commercial code-signing certificate — those cost several hundred dollars a year, which is incompatible with a zero-revenue project. Windows will therefore show "Unknown Publisher" on first launch. Verify the published SHA-256 checksum against the file you downloaded, then choose More info → Run anyway.

The checksum is published on the download page and repeated in every release note. Comparing it is a thirty-second step and it is the correct way to establish that what you received is what was built.

After installation

The app starts a local server on 127.0.0.1 and opens your default browser. Create a company, set the financial year, and enter opening balances. The books file is written under the application data directory; back it up by copying that single file, or use Data → Backup for a JSON export.

System requirements

Windows 10 or 11 on 64-bit, roughly 100 MB of disk for the application plus whatever your books grow to, and no GPU or network requirement. It runs acceptably on decade-old office hardware because there is no Electron runtime and no cloud round-trip.

Questions

Is the download safe if SmartScreen blocks it?

Verify the published SHA-256 checksum first. An unsigned binary triggers that prompt by default; the hash is how you confirm authenticity.

Does it need .NET or Python installed?

No. The distributed builds bundle what they need.

Can I run it without administrator rights?

Yes — use the portable ZIP.

Is there a 32-bit build?

The published builds are 64-bit.
